# 🏨 Hotel Booking System

A full-stack hotel booking web application built using the MERN stack. 
The application allows users to explore hotels, view room details, 
check availability, and make bookings. Hotel owners can manage their 
rooms through a dedicated dashboard.

## 🚀 Live Demo

[View Live Project](https://hotel-booking-system-rosy-eta.vercel.app/)

## ✨ Features

- User authentication
- Browse hotels and rooms
- View detailed room information
- Check room availability
- Hotel room booking
- Guest selection
- Hotel owner dashboard
- Add and manage rooms
- Responsive user interface
- REST API integration
- Email functionality
